# Freo X Ultra Feature Coverage

This app targets the US **Narwal Freo X Ultra**. Because Narwal’s official mobile app covers multiple robot generations, an app-wide feature does not automatically apply to every hardware model.

| Feature | Official X Ultra Support | Freo Control Coverage & Notes |
| --- | --- | --- |
| Vacuum, mop, both, or vacuum then mop | All four modes are documented in the [X Ultra manual](https://support.narwal.com/hc/en-us/article_attachments/33679781917197). | Four selectable modes (`Vacuum`, `Mop`, `Vacuum & mop`, `Vacuum, then mop`) with dynamic per-room selection, plus manual **Start**, **Pause**, **Resume**, and **Dock** controls. |
| Cleaning passes, suction, moisture | The [manual](https://support.narwal.com/hc/en-us/article_attachments/33679781917197) describes adjustable cleaning parameters. | Native cleaning options expose 1 or 2 passes, four suction levels, three mop moisture levels, and route preferences. Options apply to the next **Start** across selected rooms. |
| Current state and dock contact | The official app reports robot status and station state. | Battery percentage, conservative working-state labels (`Standby`, `Paused`, `Cleaning task`), and explicit station-contact readouts (`Charging contact`, `Dock contact`, `Away from dock`). |
| Live cleaning path | [X Ultra support](https://us.narwal.com/pages/product-help-freo-x-ultra) describes live track updates. | Scoped foreground MQTT streaming requests a 2-second update cadence only while the **Floorplan** tab is visible, with automatic 15-second fallback polling. |
| Cleaning history | Narwal documents [Work History](https://support.narwal.com/hc/en-us/articles/37026004442509-Work-History). | Recent cloud history records and routes can be synced on demand and cached locally alongside observed live route excerpts (bounded to 20 records, 30 days, or 48 MiB, excluded from backups). |
| Scheduled cleaning | Narwal provides a [scheduled-task guide](https://support.narwal.com/hc/en-us/articles/35244774361101-How-to-Set-up-Scheduled-Task). | Native weekly schedule viewer and editor supporting robot-timezone time selection, repeat days, enabled toggles, and room/mode configuration while preserving unrecognized protocol fields. |
| Zone schedules | The [zone-cleaning guide](https://support.narwal.com/hc/en-us/articles/37701754778253-How-to-Start-a-Zone-Cleaning) excludes scheduling. | Not offered. |
| Multiple maps | [X Ultra support](https://us.narwal.com/pages/product-help-freo-x-ultra) describes multi-map storage; the [multi-floor guide](https://support.narwal.com/hc/en-us/articles/34335936887437-Multi-Floor-Cleaning) excludes secondary-map schedules. | Room selection and edits are scoped to the active primary map and revision. Secondary-map switching is not exposed. |
| Split, merge, and rename rooms | [X Ultra support](https://us.narwal.com/pages/product-help-freo-x-ultra) describes splitting, merging, and naming rooms. | Native room boundary editor (`/map/operation` split, merge, and rename) with strict pre-write snapshots and post-write raster/metadata verification. |
| Siri & Apple Shortcuts | System voice and Shortcuts integration via iOS `AppIntents`. | Dynamic `FreoRoomEntity` room catalog, four fixed-mode room intents (`Vacuum`, `Mop`, `Vacuum & mop`, `Vacuum, then mop`), multi-room `Clean rooms`, plus `Pause` and `Stop` (recall to dock). Runs in the background (`openAppWhenRun = false`) so shortcuts work while the iPhone is locked and from HomePod. |
| Mop-washing frequency, accessories & firmware | Covered in official app settings tutorials. | Not currently exposed as write controls. |
